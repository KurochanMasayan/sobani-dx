# 患者マスタ

## 概要
訪問歯科診療の対象となる患者の情報を管理するマスタテーブル

## テーブル定義

| カラム名 | データ型 | 必須 | 説明 |
|---------|---------|------|------|
| ID | Number | ○ | 患者を一意に識別するID |
| 氏名 | Text | ○ | 患者の氏名 |
| カナ | Text | | 氏名のフリガナ |
| ステータス | Enum | ○ | 治療（長期）/治療（単発）/ケア/終了（デフォルト: 治療（長期））。終了にすると新規スケジュール生成対象外 |
| 生年月日 | Date | | 生年月日（YYYY/MM/DD形式） |
| 性別 | Enum | | 男/女 |
| 施設ID | Ref | | 施設マスタへの参照（FAC + 3桁連番） |
| 部屋番号 | Number | | 施設内の部屋番号 |
| 保険種別 | Enum | | 生活保護/後期高齢/国保 |
| 負担割合 | Enum | | 0割/1割/2割 |
| 重度医療 | Enum | | 無/有/有/非課税 |
| 要介護度 | Enum | | 非該当/要介護1〜5 |
| 介護負担割合 | Enum | | 0割/1割 |
| 自己負担有無 | Enum | | 無/有（1割）/有（2割）/有（障害/初診料のみ） |
| 訪問頻度 | Enum | | 月1/月2 |
| 治療・ケア | Text | | 訪問種別（例：ケア（月・水・金）、治療（月・水）） |
| 目的 | Text | | 訪問目的（義歯洗浄、虫歯治療、口腔ケア等） |
| 週数1 | Enum | | 基本スケジュール: 1回目の訪問週（1〜4） |
| 週数2 | Enum | | 基本スケジュール: 2回目の訪問週（1〜4）。月2の場合のみ |
| 曜日 | Enum | | 基本スケジュール: 訪問曜日（月〜日） |
| 時間 | Time | | 基本スケジュール: 訪問開始時間 |
| 事業所ID | Ref | | 居宅介護支援事業所マスタへの参照（CMP + 3桁連番） |
| 備考 | LongText | | 担当CMの連絡先等 |

## 基本スケジュール

週数1・週数2・曜日・時間の4項目で「基本スケジュール」を構成する。

- **週数1**: 1回目の訪問週（第1週〜第4週から1つ選択）
- **週数2**: 2回目の訪問週（第1週〜第4週から1つ選択）。訪問頻度が月2の場合のみ設定
- **曜日**: 訪問する曜日（1つ選択）
- **時間**: 訪問開始時間

例: 週数1=1, 週数2=3, 曜日=月, 時間=09:00 → 毎月の第1・第3月曜 09:00 に訪問

月次スケジュール生成時に、この設定に基づいて診療スケジュールが自動作成される。

### バリデーション

- 週数1 ≠ 週数2（重複禁止）
- 訪問頻度が「月2」の場合、週数2は必須
- 訪問頻度が「月1」の場合、週数2は非表示（Show_If で制御）

## ステータス

| 値 | 説明 |
|----|------|
| 治療（長期） | 継続的な治療が必要な患者（デフォルト）。スケジュール生成・手動追加ともに可能 |
| 治療（単発） | 単発の治療で訪問中の患者。スケジュール生成・手動追加ともに可能 |
| ケア | 口腔ケアのみで訪問中の患者。スケジュール生成・手動追加ともに可能 |
| 終了 | 診療終了（治療完了・転居等）。スケジュール生成対象外、手動追加時の選択肢からも除外 |

## リレーション

- **施設マスタ** ← 施設ID（多対1）
- **居宅介護支援事業所マスタ** ← 事業所ID（多対1）
