# スケジュール生成ログ

## 概要
月次スケジュール一括生成のトリガーおよび履歴管理テーブル。
レコードを追加すると、Automation Botが起動し、ステータスが終了以外の患者の基本スケジュール設定に基づいて
診療スケジュールを自動生成する。

## テーブル定義

| カラム名 | データ型 | 必須 | 説明 |
|---------|---------|------|------|
| 生成ID | Text | ○ | 自動採番（GEN-YYYYMMDDHHMMSS） |
| 対象年月 | Date | ○ | 生成対象の月（1日を指定。例: 2026/03/01） |
| 生成日時 | DateTime | | レコード作成日時（自動設定） |
| 備考 | Text | | メモ |

## バリデーション

### 重複月チェック（対象年月に設定）

同じ年月のレコードが既に存在する場合はエラー:

```
ISBLANK(
  SELECT(
    スケジュール生成ログ[生成ID],
    AND(
      MONTH([対象年月]) = MONTH([_THISROW].[対象年月]),
      YEAR([対象年月]) = YEAR([_THISROW].[対象年月])
    )
  )
)
```

## 運用フロー

1. ナビゲーションから「スケジュール生成」を選択
2. 対象年月（翌月の1日）を入力して保存
3. Bot が自動起動:
   - 患者マスタから ステータス≠終了 かつ 基本スケジュール設定済みの患者を抽出
   - 各患者の「週数1」「週数2」「曜日」「時間」に基づいて診療スケジュールを生成
   - 既存スケジュールとの重複はスキップ
4. 診療スケジュール一覧で確認・手動調整
