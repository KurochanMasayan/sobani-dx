## はじめに

### 本書の目的
本書は、そばにで使用している **カレンダー同期・PDF出力システム** の概要仕様を、社内（内製）での運用・保守へ引き継ぐことを目的としてまとめたものである。何をするツールか・どんな前提で動くか・どこを設定すれば運用できるかを、開発の専門家でなくても把握できる粒度で記述する。

### 対象読者
そばにで本システムの運用・保守を担当する方。Google スプレッドシート・カレンダー・ドライブの基本操作ができることを前提とする。

### 本書の位置づけ
本書は概要レベルの仕様書である。処理の最終的な正本は Google Apps Script（GAS）のソースコードであり、細部の挙動はソースが優先する。

---

## システム概要

本システムは、Google カレンダーの予定をスプレッドシートに取り込み、**施設ごとの月間カレンダーを PDF として自動生成し、Google ドライブに保存する** Google Apps Script ツールである。あわせて、カレンダー情報の CSV 出力（ダウンロードリンク生成）も行う。

訪問予定の一覧化と、施設へ配布・共有するためのカレンダー PDF づくりを自動化することがねらいである。通常カレンダーと歯科カレンダーの 2 系統に対応する。

---

## 利用者と利用シーン

| 利用者 | 主な操作 |
| --- | --- |
| 運営・事務担当者 | 期間を指定してカレンダーを同期し、施設別の月間カレンダー PDF を一括出力する。必要に応じて CSV を出力する。 |

操作はスプレッドシート上のメニュー／ボタンから行う想定で、専門知識がなくても実行できる。

---

## 機能一覧

| 機能 | 概要 |
| --- | --- |
| カレンダー同期 | 指定期間の Google カレンダー予定をスプレッドシートに取り込む（通常／歯科の 2 系統）。 |
| 施設別 PDF 出力 | 施設ごとに月間カレンダーを PDF 化し、ドライブの指定フォルダへ保存する。 |
| 全施設一括出力 | 施設一覧をもとに全施設の PDF をまとめて生成する。 |
| 長時間処理の自動継続 | 実行時間制限に近づくと進捗を保存し、時間トリガーで自動的に続行する。 |
| CSV 出力 | カレンダーデータを CSV（BOM 付き UTF-8）で出力し、ダウンロードリンクを発行する。 |

## システム構成

本システムは Google のサービス上で完結する。GAS を中心に、Google カレンダー・スプレッドシート・ドライブが連携する。

```
   [ Google カレンダー ]            [ Google スプレッドシート ]        [ Google ドライブ ]
   通常 / 歯科の予定    ──同期──▶   カレンダーデータ等のシート  ──▶  施設別カレンダー PDF
                                              │                       CSV ファイル
                                              ▼
                                     GAS（同期 / PDF生成 / CSV出力）
```

スプレッドシートには次のようなシートを配置する。

| シート | 役割 |
| --- | --- |
| 使い方 | 同期期間（開始日・終了日）の入力欄、CSV 出力結果のリンク表示。 |
| カレンダーデータ／歯科カレンダーデータ | 同期した予定（日付・開始／終了時刻・タイトル・コメント）。 |
| 施設カレンダー | PDF 出力用のレイアウト面（施設名・年月・出力範囲）。 |
| 合算訪問一覧 | 施設の一覧。全施設一括出力時の対象抽出に用いる。 |
| csv | CSV 出力用のデータ面。 |

## データ・入出力

### 入力（Google カレンダー）
通常カレンダー・歯科カレンダーの 2 つのカレンダー ID を対象とする。各予定はタイトル・開始／終了時刻・説明・終日フラグを持つ。

### 出力（PDF）
施設名と年月をセットしたうえで、施設カレンダー面の所定範囲を PDF 化し、ドライブの指定フォルダへ保存する。同一施設の旧 PDF は削除してから新しい PDF を保存する。

### 出力（CSV）
CSV シートの内容を BOM 付き UTF-8 で出力する。値にカンマ・改行・引用符を含む場合は適切に囲む。出力後、「使い方」シートにファイル名とダウンロードリンクを自動で表示する。

---

## 主要な処理

### カレンダー同期
「使い方」シートに入力した開始日・終了日の期間で、対象カレンダーの予定をすべて取得し、日付・時刻・タイトル・説明に整形して該当シートへ書き込む（上書き）。複数カレンダーを扱う場合は、取得結果を統合・並べ替えて出力する。

### 施設別 PDF 生成
施設名・年月をセットし、スプレッドシートの PDF 出力（エクスポート）機能を用いて所定範囲を PDF 化する。生成時には認証トークンを用いる。

### 全施設一括出力と自動継続
「合算訪問一覧」から施設一覧を取得し、施設ごとに PDF を生成する。処理が実行時間の上限（GAS は 1 回あたり約 6 分）に近づいた場合は、進捗を保存して一旦終了し、時間トリガーで残りを自動的に続行する。API のレート制限に対しては、一定回数のリトライと小休止を挟む。

> 実行時間制限への対応（進捗保存と自動継続）は、件数の多い一括処理を確実に完了させるための仕組みである。

## 運用・設定

### 事前設定
| 設定項目 | 内容 |
| --- | --- |
| カレンダー ID | 通常・歯科の 2 系統のカレンダー ID をソース内の設定に登録する。 |
| PDF 保存先フォルダ ID | 生成 PDF の保存先フォルダ ID をソース内の設定に登録する。 |
| 進捗保存 | 一括生成の進捗は GAS の Script Properties に保存され、自動継続に用いられる。 |

### 必要な権限
Google カレンダー（読み取り）・スプレッドシート・ドライブ（読み書き）・スクリプト実行の権限が必要。初回実行時に Google アカウントでの承認を行う。

---

## 制約・注意事項

- PDF の出力範囲はレイアウト面の所定範囲に固定されている（施設ごとの動的な範囲変更は想定外）。
- 同名施設の旧 PDF は削除されるため、過去版の PDF はファイルとして残らない。
- 複数カレンダーを同時に扱う場合、予定は 1 つのシートに統合して出力される。
- CSV は BOM 付き UTF-8（Excel 互換重視）。他ツールへ取り込む場合は文字コードに注意。
- GAS の実行時間制限に依存するため、施設数が多い場合は複数回に分けて自動継続される。

## 修正のしかた（メンテナンス）

このツールのプログラム（GAS）は、**コピー&ペーストで直せる**。専用のビルド作業や clasp などの開発ツールは不要である。

1. 操作の起点となるスプレッドシートを開く。
2. メニュー「拡張機能」→「Apps Script」を開く。
3. 左のファイル一覧から、直したい処理のファイルを選ぶ（同期・PDF 出力・CSV 出力など、処理ごとにファイルが分かれている）。
4. 該当箇所を書き換える（用意したコードを貼り付ける）。
5. 保存すれば反映される。

> 元のコードは TypeScript で書かれているが、実際に動いているのは Apps Script エディタ上のコードである。小さな修正は、エディタ上のコードを直接コピー&ペーストで直す形で問題ない。
> カレンダー ID・保存先フォルダ ID などの設定値は、コードの設定部分を書き換える。直す前に元のコードを控えておくと、元に戻したいときに安心。
