## はじめに

### 本書の目的
本書は、そばにの在宅医療業務で使用している **居宅療養管理指導書 自動作成システム** の概要仕様を、社内（内製）での運用・保守へ引き継ぐことを目的としてまとめたものである。これまで外部委託で開発してきた本ツールについて、何をするものか・どんな前提で動くか・どこを設定すれば運用できるかを、開発の専門家でなくても把握できる粒度で記述する。

### 対象読者
そばにで本システムの運用・保守を担当する方。Google スプレッドシートと Google ドライブの基本操作ができることを前提とする。

### 本書の位置づけ
本書は概要レベルの仕様書である。実際の処理の最終的な正本は Google Apps Script（GAS）のソースコードであり、細部の挙動はソースが優先する。設定値の具体的な ID 等は本番環境の値を別途参照すること。

---

## システム概要

居宅療養管理指導書は、訪問診療を行った患者ごとに月次で作成する書類である。本システムは、その作成作業を自動化する Google Apps Script ツールである。

患者情報と当月の訪問カレンダーを CSV で受け取り、あらかじめ用意した指導書テンプレート（スプレッドシート）に値を差し込んで、**居宅介護支援事業所ごと・年月ごとに 1 つのスプレッドシートを作成し、その中に患者 1 名 = 1 シートとして指導書を生成する**。手作業での転記をなくし、記載漏れと作成時間を削減することがねらいである。

> 出力はスプレッドシート上のシート生成までを範囲とする。PDF 化や他システムとの連携は本システムの対象外である。

## 利用者と利用シーン

| 利用者 | 主な操作 |
| --- | --- |
| 事務担当者 | 月次で患者 CSV・カレンダー CSV をドライブに配置し、テンプレートのメニューから生成を実行する。3 件以上訪問がある患者の訪問回を選択する。 |

毎月の流れは「CSV を所定フォルダに置く → テンプレートを開いてメニューを押す → 生成完了を確認する」というシンプルな運用を想定している。

## 機能一覧

| 機能 | 概要 |
| --- | --- |
| 指導書シート自動生成 | 患者 CSV とカレンダー CSV を突合し、患者ごとに指導書シートを生成する。 |
| 事業所別ファイル管理 | 居宅介護支援事業所ごと・年月ごとに 1 つのスプレッドシートへまとめる。 |

| 訪問①／②の自動割り当て | 同月に 2 件の訪問がある患者は、日付の早い方を訪問①、遅い方を訪問②とする。 |
| 訪問回の手動選択 | 同月に 3 件以上訪問がある患者は「訪問選択」シートで使用する回を選ぶ。 |
| 長時間処理の自動継続 | GAS の実行時間制限（約 6 分）に達した場合、未処理分を保存し時間トリガーで自動継続する。 |
| 進行状況の可視化 | 「進行管理」「処理キュー」シートで実行状況・残件数を表示する。 |

## システム構成

本システムは Google のサービス上で完結する。GAS が処理の中心となり、入力（CSV）と出力（スプレッドシート）はいずれも Google ドライブ上に置かれる。

```
   [ Google ドライブ ]                         [ Google ドライブ ]
   患者情報CSV / カレンダーCSV   ──▶  GAS  ──▶  事業所別スプレッドシート
   （所定フォルダに配置）        （差し込み処理）  （患者ごとにシート生成）
                                     │
                                     ▼
                          テンプレートブック（同一スプレッドシート内）
                          ・原本（指導書テンプレート）
                          ・事業所ファイル台帳（生成物のURL管理）
                          ・進行管理 / 処理キュー / 訪問選択
```

テンプレートブック（操作の起点となるスプレッドシート）には、以下のシートを 1 冊にまとめて配置し、テンプレート・台帳・ログ・キューを一元管理する。

| シート | 役割 |
| --- | --- |
| 原本 | 指導書のテンプレート。複製して各患者のシートを作る。 |
| 事業所ファイル台帳 | 生成したスプレッドシートの URL・フォルダ ID 等を管理する。 |
| 進行管理 | 直近の実行時刻・ステータス・処理人数・残り人数を表示する。 |
| 処理キュー | 処理対象の患者・施設・状態を可視化する。 |
| 訪問選択 | 3 件以上訪問がある患者の使用回を選択する。 |

## 入力データ

入力は 2 種類の CSV である。いずれも文字コードは **Shift_JIS（cp932）** を前提とする。

### 患者情報 CSV
患者の属性と指導書の本文項目を保持する。`患者ID` を突合キーとする。主な列は次のとおり。

- 患者ID / 患者名 / 生年月日 / 年齢 / 性別 / 郵便番号 / 住所 / 診断名
- 居宅介護支援事業所 / 寝たきり度 / 認知度 / 介護認定
- 日常生活や介護サービスを利用する上での留意点
- 定期訪問①（著変なし／変更あり）／ 定期訪問②（著変なし／変更あり）

### カレンダー CSV（月次）
当月の訪問予定を 1 訪問 = 1 行で保持する。ファイル名は `calendar_data_YYYY-MM.csv` 形式。`orcaID` が患者情報 CSV の `患者ID` に対応する。主な列は `日付 / 開始時間 / 終了時間 / 医師名 / orcaID / 患者名 / 定期訪問 / 施設 / 訪問タイプ`。

> CSV 上で「①／②」や「Ⅱ／Ⅲ」等が文字化けしていても、処理側で正しい文字に補正してから扱う。

## 出力仕様

- **出力単位**: 居宅介護支援事業所ごと・年月ごとに 1 つのスプレッドシートを作成する。
- **シート単位**: 患者ごとにテンプレート（原本）を複製し、`患者名_訪問日`（例: `テスト一郎_2025-12-01`）のシート名で生成する。
- **保存先**: ドライブ上の出力フォルダ（`OUTPUT_FOLDER_ID` で指定）の下に、実行日時フォルダ（例: `2025-12-20-103000`）を作成して格納する。
- **再利用**: 同一バッチ内で同じ事業所のスプレッドシートが既にあれば再利用し、シートを追加する。台帳で年月＋事業所名＋実行 ID により照合する。

## 主要な処理

### 全体の流れ
1. メニュー「居療管指導書」→「指導書生成（開始）」を実行する。
2. ドライブから 2 つの CSV を読み込み、患者 CSV を `患者ID` でインデックス化する。
3. カレンダー CSV から「定期訪問」の行だけを残し、患者ごとに訪問日の昇順でまとめる。
4. 各患者の訪問件数に応じて指導書を生成する（下記ルール）。
5. 処理キューを施設名でソートし、同一施設の患者を連続処理する（書き込み効率化）。
6. 実行時間が約 5 分に達したら一旦終了し、未処理分を残して時間トリガーで自動継続する。

### 訪問件数ごとの扱い
| 当月の定期訪問件数 | 扱い |
| --- | --- |
| 1 件 | 訪問①のみ生成する。 |
| 2 件 | 早い日付を訪問①、遅い日付を訪問②として生成する。 |
| 3 件以上 | 自動生成せず「訪問選択」シートに登録し、使用回の選択後に処理する。 |

3 件以上の患者の既定選択は、全 3 回なら 1・2 回目、全 4 回なら 1・3 回目を使用する。

### 症状・経過欄の扱い
各訪問について、まず「定期訪問①／②（変更あり）」を確認し、内容があればそれを採用する。空欄の場合は「（著変なし）」の文面を使用する。現行テンプレートでは訪問①の欄のみを出力対象とする（②の出力は今後の拡張）。

## 運用・設定

### 事前設定（Script Properties）
GAS の「スクリプト プロパティ」に、以下のドライブ フォルダ ID を登録する。

| プロパティ名 | 内容 |
| --- | --- |
| `PATIENT_CSV_FOLDER_ID` | 患者 CSV を配置するフォルダ |
| `CALENDAR_CSV_FOLDER_ID` | カレンダー CSV を配置するフォルダ |
| `OUTPUT_FOLDER_ID` | 生成物の保存先フォルダ |

### 月次の操作手順
1. 最新の患者 CSV・カレンダー CSV を所定フォルダに配置する。
2. テンプレートスプレッドシートを開き、メニュー「居療管指導書」→「指導書生成（開始）」を押す。
3. 自動で進行し、時間制限に達した分は 1 分後の時間トリガーで自動継続する（手動での再実行は不要）。
4. 「進行管理」シートのステータスが「完了」になれば当月分は終了。処理済み CSV は自動的に削除される。
5. 3 件以上訪問の患者がある場合は「訪問選択」で回を選び、「選択患者を処理」を実行する。

### 必要な権限
ドライブ（読み書き）・スプレッドシート・スクリプト実行の権限が必要。初回実行時に Google アカウントでの承認を行う。

## 制約・注意事項

- 出力はスプレッドシートのシート生成まで。PDF 化や他システム連携は対象外。
- 同月に 3 件以上の定期訪問がある患者は自動生成されず、手動選択が必要。
- 患者名をキーとして扱う処理があり、同名患者は後のデータで上書きされる場合がある。
- 文字コードは Shift_JIS（cp932）前提。UTF-8 など他コードの CSV は想定外。
- GAS の実行時間制限（約 6 分）に依存するため、件数が多い月は複数回に分けて自動継続される。

## 修正のしかた（メンテナンス）

このツールのプログラム（GAS）は、**コピー&ペーストで直せる**。専用のビルド作業や clasp などの開発ツールは不要である。

1. テンプレートスプレッドシートを開く。
2. メニュー「拡張機能」→「Apps Script」を開く。
3. 左のファイル一覧から、直したい処理のファイルを選ぶ（例: `main.gs`＝全体の制御、`template.gs`＝セルへの差し込み、`data-loaders.gs`＝CSV 読み込み など）。
4. 該当箇所を書き換える（用意したコードを貼り付ける）。
5. 保存すれば反映される。

> フォルダ ID などの設定値は、コードではなく「プロジェクトの設定 → スクリプト プロパティ」で変更する。
> テンプレートのレイアウト（差し込み先のセル）を変えたいときは、「原本」シートと、コード側のセル指定（本書「テンプレート項目マッピング」参照）の両方を合わせる必要がある。
> 直す前に元のコードを控えておくと、元に戻したいときに安心。
