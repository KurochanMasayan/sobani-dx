## はじめに

### 本書の目的
本書は、そばにの在宅医療業務で使用している **在宅診療計画書 自動作成システム** の概要仕様を、社内（内製）での運用・保守へ引き継ぐことを目的としてまとめたものである。何をするツールか・どんな前提で動くか・どこを設定すれば運用できるかを、開発の専門家でなくても把握できる粒度で記述する。

### 対象読者
そばにで本システムの運用・保守を担当する方。Google スプレッドシートとドライブの基本操作ができることを前提とする。

### 本書の位置づけ
本書は概要レベルの仕様書である。処理の最終的な正本は Google Apps Script（GAS）のソースコードであり、細部の挙動はソースが優先する。

> 本システムは、別冊「居宅療養管理指導書 自動作成システム」と構成・操作の考え方が共通している。両者は対象書類が異なる姉妹ツールである。

---

## システム概要

本システムは、患者情報の CSV から **在宅診療計画書** を自動生成する Google Apps Script ツールである。

あらかじめ用意した計画書テンプレート（スプレッドシート）に CSV の値を差し込み、**居宅介護支援事業所ごと・年月ごとに 1 つのスプレッドシートを作成し、その中に患者 1 名 = 1 シートとして計画書を生成する**。手作業での転記をなくし、作成時間と記載漏れを削減することがねらいである。

---

## 利用者と利用シーン

| 利用者 | 主な操作 |
| --- | --- |
| 事務担当者 | 患者 CSV をドライブの所定フォルダに配置し、テンプレートのメニュー／ボタンから生成を実行する。 |

毎月の流れは「CSV を所定フォルダに置く → テンプレートを開いて実行する → 生成結果を確認する」というシンプルな運用を想定している。

## 機能一覧

| 機能 | 概要 |
| --- | --- |
| 計画書シート自動生成 | 患者 CSV を読み込み、患者ごとに計画書シートを生成する。 |
| 事業所別ファイル管理 | 居宅介護支援事業所ごと・年月ごとに 1 つのスプレッドシートへまとめる。 |
| 長時間処理の自動継続 | 実行時間制限に達した場合、未処理分を残して自動的に続行する。 |
| 進行状況の可視化 | 「進行管理」シートで処理状況を表示する。 |

## システム構成

本システムは Google のサービス上で完結する。GAS が処理の中心となり、入力（CSV）と出力（スプレッドシート）はいずれも Google ドライブ上に置かれる。

```
   [ Google ドライブ ]                  [ Google ドライブ ]
   患者情報CSV   ──────▶  GAS  ──────▶  事業所別スプレッドシート
   （所定フォルダに配置）  （差し込み処理）  （患者ごとにシート生成）
                              │
                              ▼
                   テンプレートブック（同一スプレッドシート内）
                   ・原本（計画書テンプレート）
                   ・事業所ファイル台帳 ・進行管理
```

| シート | 役割 |
| --- | --- |
| 原本 | 計画書のテンプレート。複製して各患者のシートを作る。 |
| 事業所ファイル台帳 | 生成したスプレッドシートの管理台帳（年月・事業所名・URL・最終更新）。 |
| 進行管理 | 処理状況を表示する（存在しない場合は自動作成）。 |

---

## 入力データ

入力は患者情報の CSV である。文字コードは **Shift_JIS（cp932）** を前提とする。列は位置（A〜M 列）で対応づける。

| 列 | 内容 |
| --- | --- |
| A | 患者名 |
| B | 生年月日（例: 昭和60年07月18日） |
| C | 年齢（「歳」は自動で除去） |
| D | 性別 |
| E | 郵便番号 |
| F | 住所 |
| G | 診断名（複数行可） |
| H | 施設名（事業所名） |
| I | 寝たきり度 |
| J | 認知度 |
| K | 介護認定 |
| L | 在宅療養計画の要点（複数行可） |
| M | 日常生活や介護サービスを利用する上での留意点 |

---

## 出力仕様

- **ファイル名**: `{年月}_{事業所名}`（例: `2025-12_テスト施設`）。
- **シート名**: `{患者名}_{日付}`（例: `テスト一郎_2025-12-13`）。
- **まとめ方**: 同一事業所・同一年月の患者は 1 つのスプレッドシートにまとめる。
- **保存先**: ドライブ上の出力フォルダ（`OUTPUT_FOLDER_ID` で指定）。

## 運用・設定

### 事前設定（Script Properties）
GAS の「スクリプト プロパティ」に、以下のドライブ フォルダ ID を登録する。

| プロパティ名 | 内容 |
| --- | --- |
| `PATIENT_CSV_FOLDER_ID` | 患者 CSV を配置するフォルダ |
| `OUTPUT_FOLDER_ID` | 生成物の保存先フォルダ |

### 月次の操作手順
1. 患者 CSV を `PATIENT_CSV_FOLDER_ID` のフォルダに配置する。
2. テンプレートスプレッドシートを開き、メニュー「在宅診療計画書」→「計画書生成（開始）」、またはボタンを実行する。
3. 処理が完了すると、出力フォルダに事業所別スプレッドシートが生成される。
4. 実行時間が制限に達した場合は、1 分後に自動的に続きから再開される。

### 必要な権限
ドライブ（読み書き）・スプレッドシート・スクリプト実行の権限が必要。初回実行時に Google アカウントでの承認を行う。

---

## 制約・注意事項

- 処理完了後、読み込んだ CSV は自動的にゴミ箱へ移動される。
- 患者名をキーとして扱うため、同名患者がいる場合は後のデータで上書きされる。
- 文字コードは Shift_JIS（cp932）前提。UTF-8 など他コードの CSV は想定外。
- GAS の実行時間制限（約 6 分）に依存するため、件数が多い場合は複数回に分けて自動継続される。

## 修正のしかた（メンテナンス）

このツールのプログラム（GAS）は、**コピー&ペーストで直せる**。専用のビルド作業や clasp などの開発ツールは不要である。

1. テンプレートスプレッドシートを開く。
2. メニュー「拡張機能」→「Apps Script」を開く。
3. 左のファイル一覧から、直したい処理のファイルを選ぶ（例: `main.gs`＝全体の制御、`template.gs`＝セルへの差し込み、`config.gs`＝設定 など）。
4. 該当箇所を書き換える（用意したコードを貼り付ける）。
5. 保存すれば反映される。

> フォルダ ID などの設定値は、コードではなく「プロジェクトの設定 → スクリプト プロパティ」で変更する。
> テンプレートのレイアウト（差し込み先のセル）を変えたいときは、「原本」シートと、コード側のセル指定（本書「テンプレート項目マッピング」参照）の両方を合わせる必要がある。
> 直す前に元のコードを控えておくと、元に戻したいときに安心。
